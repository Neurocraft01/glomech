# Glomech Engineering Pvt. Ltd - Official Website

This is a modern, mobile-first website for Glomech Engineering Pvt. Ltd, a leading manufacturer in Pimpri-Chinchwad, Pune.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (CSS Modules)
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Features
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Premium Aesthetics**: Industrial dark theme with glassmorphism and modern typography.
- **Dynamic Animations**: Smooth scroll reveals and interactive elements using Framer Motion.
- **SEO Optimized**: Pre-configured metadata for better search visibility.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
